## 再開後（11/17 夜）に足したこと

- `recorder facade all <棟>` の工程：views → detect → fuse → **refine**（箱の縁を凹みの外形＝明るい壁と暗い凹みの境目に寄せる）→ **regularize**（同じ段の幅・列の線で直し、2 つにまたがる箱と重複を捨て、同じ列の窓をまとめて左右の縁を探し直す）→ compare。結果は `out/facade/<棟>/<面>/final.json`。
- 本部棟 f6 の結果：写真 18 枚、箱 337 → 照合した窓 61 → 整えた窓 48。模型の窓 45 と全部対応。ずれの中央値：左右 5〜6 cm、上端 1.3 cm、下端 0.66 m。下端の差は、模型が手すりより上のガラスだけを窓にしているため。凹みの外形（LOD3 の窓の定義）は写真の方が正しいことを、重ね画像（`out/facade/honbu/f6/_final_042900775.jpg`）で確かめた。
- `recorder lod3 build --windows photos`：写真から出した窓（2 枚以上で照合、σ つき、根拠の写真つき）を使う。出どころは新しい区分「正面化した写真を何枚も使い、窓を検出して写真どうしで照合した」（コード 801）。本部棟の窓の等級：500 相当 32 → 61、1000 相当 47 → 38、2500 相当 37 → 19（f6 だけ写真の窓に替えた時点）。XSD 合格・立体は閉じている。
- 材質：外壁の読み係の報告（`data/reports/<棟>/gaiheki_<面>.json`）の `materials` で `where: "wall"` の物を、その面の壁に gen 属性（外装材・確からしさ・出どころ 802 写真判読・根拠の写真）として書く。
