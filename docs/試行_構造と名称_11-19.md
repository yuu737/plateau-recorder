正解と判定の規則は、調べ役に渡す前に `data/truth/構造と名称_11-19.md` に固定した。
今朝の図書館の建築年の試験（`試行_建築年_図書館_11-19.md`）からの直し：①写真を読む係と Web を調べる係を分けた、②持ち主のサイトに絞って先に検索させた、③ OSM で位置から名前を引く確認を足した。

## よかった所：別の建物の構造を流用しなかった
Web の係はどちらも、ほかの建物の「鉄筋コンクリート造」に行き当たった（研究実験棟Ⅳ RC 地上 7 階、クラブハウス棟 RC 地上 5 階、100 周年記念アリーナ、札幌の藤学園講堂棟 SRC など）。どれも同じ建物ではないとして根拠に使わなかった。特にクラブハウス棟は「地上 5 階 RC」で本部棟と階数が同じで、流用すれば見た目は埋まるが根拠の無い値になっていた。

## わかったこと
1. **名称は 2 棟とも取れた。** 写真の看板と、持ち主のページ・OSM の 2 つで裏が取れる。
2. **構造は 2 棟とも Web に記述が無かった。** 大学の公開資料（キャンパス紹介・図書館の沿革・2023 年度の事業報告書）には、建物ごとの構造が書かれていない。写真で言えるのは「非木造（610）」まで。地震の被害想定は、木造か非木造かと建築年代で分けることが多いので、610 と建築年でも使い道はある。ただし RC と SRC は分からない。
3. **費用は下がらなかった。むしろ増えた。** 原因は写真。今朝の図書館（係 1 つ）は約 15.3 万トークン。今回は図書館で 写真の係 14.3 万＋Web の係 7.2 万＝21.4 万、本部棟で 写真の係 22.2 万（33 枚）＋Web の係 6.7 万＝28.8 万。写真 1 枚あたり約 7〜8 千トークン（元の解像度のまま読ませた）。次は写真を縮めて読ませるか、文字の写った写真だけを選んで読ませる。
4. **ついでに分かったこと**：図書館のフロアマップ（https://www.meijo-u.ac.jp/library/guide/floor/ ）に「本館 5 階 4 階 3 階 2 階 1 階 地下 1 階」とある（私が照合）。棟 JSON の数え係が空堀から「地下の段」と読んだ仮説と合う。
