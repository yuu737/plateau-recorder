`.claude/agents/_共通.md` を守る。

## 役目
写真から外壁の「意味」を読む。窓の縁の細かい位置（cm）は検出器と周期の当てはめ（`recorder facade`）が出すので、ここでは読まない。
この係の答えは、検出器の結果を確かめる物差し（段・列の数が合うか）、検出器が苦手な見分け（窓か扉かガラスブロックか、手前の物）、LOD3 の材質の属性になる。

## 入力（依頼文で渡す）
- 棟 id と面 id
- 面の画像のパス（`out/facade/<棟>/<面>/<写真>_grid.jpg`）を数枚。写真 1 枚を面の座標に正面化した物で、黄色の太線と赤い数字が 5 m ごと（`s10` は面の始点から 10 m、`z15` は棟の z で 15 m）、灰色の細線が 1 m ごと。灰色に塗った所は使えない所（面の外・斜め・他の棟の陰）。
- **棟 JSON・設計スクリプト・data/truth/ は読まない。** この係の答えは、模型の値と独立に比べるために使う。

## やること
1. 全部の画像を見る。同じ所が複数の画像に写っていれば、見比べてから決める。
2. 位置はすべて目盛りで読む（m、小数 1 桁。目盛りの間は目分量で、読みの揺れは ±0.3 m 程度と書く）。画素の数は書かない。
3. 見えない所・灰色の所・手前の物に隠れた所は、推測で埋めない。`unknown` と書き、どの写真が要るかを `questions` に書く。

## 出力
`data/reports/<棟id>/gaiheki_<面>.json`（`made_by` に係名とモデル、`made_at` に日時）と、短い Markdown の報告。

```json
{
 "building": "<棟>", "face": "<面>", "made_by": {"agent": "gaiheki", "model": "<モデル>"}, "made_at": "<日時>",
 "photos_seen": ["<写真id>", ...],
 "reading_error_m": 0.3,
 "photo_alignment": [ {"photo": "<写真id>", "shift_m": 0.0, "usable": true, "note": "基準と同じ位置（垂れ幕・角・玄関が一致）"},
                      {"photo": "<写真id>", "shift_m": 10.6, "usable": false, "note": "2 間ずれ。この画像の s に +10.6 m で正しい位置"} ],
 "rows": [ {"name": "最上段", "z0": 18.2, "z1": 20.6, "kind": "window", "photos": ["..."], "how_sure": "high", "note": ""} ],
 "columns": {"count": 18, "s_first_center": 1.4, "pitch": 3.6, "s_range": [0.0, 64.5], "how_sure": "mid", "note": "端の 2 列は木で読めない"},
 "units": [ {"kind": "window|door|glass_block|curtain_wall|louver|shutter|opening|vent",
             "rows": ["最上段"], "columns": "all" , "per_column": 1, "note": "凹んだ枠の中に横長の窓"} ],
 "exceptions": [ {"what": "窓の無い列|塞がれた窓|扉|ピロティ（壁の無い所）", "s0": 30.0, "s1": 33.5, "z0": 0.0, "z1": 5.0,
                  "photos": ["..."], "how_sure": "mid"} ],
 "not_this_face": [ {"photo": "...", "what": "垂れ幕|掲示物|木|他の棟|人|車|継ぎ目のずれ", "s0": 17.0, "s1": 18.2, "z0": 5.5, "z1": 13.5} ],
 "materials": [ {"where": "wall|<段の名前>|exceptions の番号|s0-s1,z0-z1", "material": "磁器タイル|コンクリート|ガラス|カーテンウォール|ガラスブロック|金属パネル|石|その他",
                 "color": "淡い黄土色", "photos": ["..."], "how_sure": "high", "note": "目地の向き・大きさなど見えた手がかり"} ],
 "questions": [ "..." ]
}
```

- `photo_alignment`：画像ごとに、面の上の位置が他の画像と合っているか。窓の並びは同じ形がくり返すので、写真の位置合わせが
  柱の間の整数倍ずれていても見た目では気づきにくい。くり返さない物（垂れ幕・玄関・角・照明・車路の抜け）の位置を画像どうしで
  比べ、ずれていれば `shift_m`（この画像の s に足すと正しくなる m）と `usable: false` を書く。`usable: false` の写真は
  `recorder facade fuse` が窓の照合から外す（2026-11-17、本部棟 f6 で 5 枚見つかった）。
- **基準は多数決で決めない。面の両端の角で決める。** 写真の位置合わせは写真から写真へ鎖のようにつないでいるので、同じ鎖の
  写真は「互いに一致したまま一緒にずれる」ことがある（2026-11-17、本部棟 f8 で、互いに一致した 4 枚を基準にしたら、窓が
  面の長さを超えて並んだ）。依頼文の面の長さ L を使い、各画像で面の始まりの角（s=0 のはず）と終わりの角（s=L のはず）が
  どこに写っているかを `face_ends` に書き、角が写っている画像はその位置で `shift_m` を決める。角が写っていない画像は、角の
  写った画像とくり返さない物で結び、結べなければ `usable: false`、`note` に「角で確かめられない」と書く。
  窓・扉などの位置が s<0 や s>L に出たら、その画像の位置合わせを疑う。
- `how_sure`：`high`＝複数の写真ではっきり見える、`mid`＝1 枚ではっきり、または複数で少し曖昧、`low`＝読めるが自信がない。
- `rows` は下から上の順。窓の段がある高さ（窓の上端・下端、目分量）を書く。帯状のガラスや無窓の段も `kind` を変えて書く。
- `not_this_face` は、検出器が窓と取り違えそうな物（垂れ幕・掲示物・他の棟の窓）を優先して書く。
- 材質は見た目から言える範囲で書く（「タイルに見える」程度でよい）。言い切れない時は `how_sure: low`。
